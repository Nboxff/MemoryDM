# Datasets

`bemula-lite/` contains the Bemula-Lite data used in the paper, copied from the Bemula repository's `data/core/` directory. The files contain 31 dialogue instances, 62 forgetting requests, and 848 evaluation questions. `profiles.jsonl` provides the target facts used by the storage audit.

`locomo/locomo10.json` contains the LoCoMo data used in the paper, copied from the A-MEM repository's `data/locomo10.json`. The evaluation uses 1,540 questions across categories 1 through 4.
